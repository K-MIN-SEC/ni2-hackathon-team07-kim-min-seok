# 달토끼 키우기 리뷰 수동 판정 기준

모바일 방치형 RPG "달토끼 키우기"의 한국어 스토어 리뷰. 별점은 일부러 주지 않는다. **리뷰 내용만으로** 판정한다.

## 1. 전체 감성 `s` (하나만)
- **긍정**: 좋다는 평가만 있음 (재밌다, 갓겜, 귀엽다, 추천, 무과금도 할만함 등)
- **부정**: 불만·문제 제기만 있음
- **혼합**: 긍정과 부정이 **둘 다 실질적으로** 있음. 예: "재밌는데 과금 심함", "다 좋은데 발열이 심해요"
- **중립**: 감정이나 평가가 드러나지 않음 (단순 정보, 의미 없는 글, 아무 문제도 드러나지 않는 순수 질문)

특수 규칙
- **문의·신고형 글**: 구체적인 문제(접속 불가, 계정 날아감, 결제했는데 미지급, 업데이트 안 됨 등)가 확실히 보이면 **부정**이다. 질문만 있고 문제가 무엇인지 너무 애매하면 **중립**이다.
- **개선 요청**: 구체적인 결핍이나 문제를 지적하면("코스튬이 너무 적어요, 늘려주세요") 그 주제에 **부정**이다. 응원성 요청("앞으로도 업데이트 많이 해주세요")은 부정이 아니다.
- **부정어 처리**: "렉 없음", "과금유도 없음", "전 한 번도 튕긴 적 없어요"는 해당 주제에 **긍정**이다.
- 반어와 비꼼은 실제 의도로 판정한다 ("열심히 돈 버세요~" → 부정).

## 2. 주제 `t` (복수 가능) + 주제별 감성
각 주제의 값은 `긍정|부정|중립|혼합` 중 하나로, 그 주제에 대한 감성이다.

| 주제 | 포함 범위 (커뮤니티 표현 포함) |
|---|---|
| 과금 | 현질, 과금, 무과금/무자본, 가챠, 뽑기, 확률("레전드 안 뜸"), 패스, 패키지, 결제 가격, 환불, 과금유도, 광고제거 구매 및 가격 |
| 버그 | 튕김/팅김, 렉/버벅, 접속불가, 서버 불안정, 로딩, 발열, 최적화, 배터리, 오류/에러, 업데이트·설치 실패, 결제·구매·쿠폰 후 아이템 미지급(시스템 오류) |
| 콘텐츠 | 스토리, 챕터, 보스(패턴/재미), 던전, 이벤트, 콜라보, 스킬/무기/룬 시스템, 길드, 서바이벌 모드, 할 거리 많음/없음, 지루함, 컨텐츠 고갈, 업데이트 볼륨·주기 |
| 운영 | 계정 소실·연동·복구, 쿠폰(아이폰 쿠폰 입력 불가 포함), 고객센터/CS/문의 답변, 소통·피드백 반영, 공지, 점검 보상, 신규 서버, 이용 제한 |
| 밸런스/성장 | 난이도, 보스가 너무 셈, 성장 속도·정체, 전투력, 재화·보상 수급("루비 많이 줌", "보상 짜다"), 랭킹 격차, 오프라인/방치 보상 |
| UI/편의성 | UI·글씨 크기, 절전모드, 화면 회전/가로세로, 자동화 기능, 가이드/튜토리얼/설명 부족, 조작 불편 |
| 캐릭터/아트 | 귀여움, 캐릭터, 코스튬/스킨, 일러스트, 그래픽, 연출, 성우/더빙, BGM, 사운드 |
| 광고 | 게임 내 광고 시청, 광고 보상, 광고 과다·강제. (광고 보다가 튕김 → 광고+버그. 광고제거 *구매* → 과금. 외부 마케팅 광고 언급은 제외) |
| 일반 | 위 주제에 해당하는 내용이 없는 전반적 평가("재밌어요", "방치형 원탑"). **일반은 다른 주제와 함께 쓰지 않는다.** |

- 게임 이름 "달토끼 키우기"나 장르명 "방치형"이 나왔다는 것만으로는 주제가 아니다.
- 주제가 하나라도 있으면 일반은 쓰지 않는다. 주제가 없으면 `{"일반": <전체감성>}`으로 쓴다.
- 전체 감성이 혼합이면, 보통은 주제마다 긍정·부정이 나뉜다. 예: "캐릭터 귀여운데 발열 심함" → s=혼합, t={"캐릭터/아트":"긍정","버그":"부정"}. 반대로 "재밌는데 발열 심함"은 긍정 쪽이 전반 평가라서 t={"버그":"부정"}, s=혼합이다.

## 3. 출력 형식
입력 파일의 각 줄 `{"id":..., "text":...}`마다 출력 파일에 한 줄씩 JSON을 쓴다 (입력과 같은 순서, 빠짐없이):
```
{"id": "<그대로>", "s": "혼합", "t": {"과금": "부정", "콘텐츠": "긍정"}}
```
- s는 긍정, 부정, 중립, 혼합 중 하나만 쓴다.
- t의 키는 위 표의 9개 주제명만 쓴다(철자 그대로: 과금, 버그, 콘텐츠, 운영, 밸런스/성장, UI/편의성, 캐릭터/아트, 광고, 일반).
- 다른 텍스트는 쓰지 않는다.
