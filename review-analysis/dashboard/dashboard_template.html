리뷰 분석

리뷰 CSV를 넣으면 바로 분석합니다

감성·주제 라벨이 붙은 스토어 리뷰 파일을 넣으면, 주제별 긍정·부정과 고쳐야 할 우선순위, 지켜야 할 장점, 버전별 추이를 이 화면에서 바로 계산해 보여 줍니다.

또는 이 화면 아무 곳에나 파일을 끌어다 놓으세요 · 파일은 브라우저 밖으로 전송되지 않습니다

  1. 1. 파일 넣기파일을 여러 개 넣으면 누적할지 교체할지 고를 수 있습니다
  2. 2. 바로 집계감성 분포, 주제별 긍정·부정, 키워드를 다시 계산합니다
  3. 3. 결과 확인개선 우선순위와 장점, 숫자마다 근거 리뷰까지

새 파일을 어떻게 반영할까요?
CSV 형식 안내

이 대시보드는 분류(라벨)가 끝난 리뷰 CSV를 읽어 브라우저 안에서 모든 수치를 계산합니다. 파일은 어디에도 전송되지 않습니다.

열필수설명
content필수리뷰 본문
date필수작성 시각 (YYYY-MM-DD 또는 YYYY-MM-DD HH:MM:SS)
rating필수별점 1~5
sentiment필수리뷰 전체 감성: 긍정·부정·중립·혼합
sent_<주제>필수(1개 이상)주제별 감성. 예: sent_과금, sent_버그, sent_일반. 언급 없으면 빈칸
keywords선택주제/키워드를 |로 연결. 예: 버그/튕김|과금/뽑기
version, thumbs_up, store, title, review_id, topics, label_source선택버전별 분석·좋아요 가중치·스토어 구분 등에 사용. review_id가 있으면 파일을 누적할 때 같은 리뷰를 한 번만 셉니다. label_source: rule=규칙 판정, manual=AI 판정

라벨이 없는 원본 리뷰는 먼저 python scripts/ml_classify.py predict 원본.csv 결과.csv로 분류한 뒤 결과 CSV를 불러오세요. 형식은 data/reviews_labeled.csv와 같습니다.

    주제별 긍정·부정 비율

    각 리뷰가 언급한 주제마다 따로 매긴 감성입니다. 리뷰 하나가 여러 주제에 들어갈 수 있습니다. 막대 오른쪽 숫자는 그 주제를 언급한 리뷰 수와 전체 대비 비중입니다. 모든 차트는 아래 '표로 보기'로 정확한 수치를 확인할 수 있습니다.

      리뷰 전체 감성 (내용 기준)

      별점과 내용 감성의 차이

      감성 × 주제별 키워드 분포

      선택한 주제·감성 리뷰 중 각 키워드를 언급한 리뷰의 비율입니다(한 리뷰가 여러 키워드를 언급할 수 있어 합계가 100%를 넘을 수 있음). 키워드는 커뮤니티 표현을 묶은 대표어입니다. 예를 들어 '튕김'에는 튕김·팅김·강제종료가 들어갑니다.

      대표 키워드

      자주 나온 표현 (원문 단어)

      원문 단어를 그대로 센 값이라 "하지", "스킬도"처럼 의미가 약한 단어가 섞일 수 있습니다. 해석은 왼쪽 대표 키워드를 기준으로 하세요.

      고쳐야 할 우선순위

      지켜야 할 장점

      버전별 추이

      리뷰를 쓴 시점의 앱 버전(마이너 버전, 예: v1.32.x) 기준입니다. 막대·점을 클릭하면 그 버전의 리뷰를 볼 수 있습니다.

      버전별 리뷰 수 (전체 버전)

      버전별 부정·혼합 리뷰 비율

      버전별 주제별 부정·혼합 언급 수
