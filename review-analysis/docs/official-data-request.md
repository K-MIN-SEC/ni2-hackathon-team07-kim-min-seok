# ㈜에이블게임즈 공식 데이터 제공 요청 (초안)

> 발송 전 팀 검토용 초안입니다. 수신자, 기간, 연락처를 채워 보내 주세요.

**제목:** [NI2.0 AID 해커톤 7팀] 달토끼 키우기 리뷰·업데이트 데이터 제공 요청

안녕하세요, NI2.0 AID 해커톤 7팀(카페인 중독)입니다.
과제 「유저 리뷰 감성 분석 대시보드」를 진행하면서 업데이트별 사용자 반응을 분석하고자 합니다. 공개 스토어 웹페이지에서 리뷰를 자동 수집하는 것은 각 스토어의 이용 조건(robots.txt)에 맞지 않아, 개발사에서 공식 경로로 확인할 수 있는 데이터를 요청드립니다.

## 요청 데이터

| 우선순위 | 데이터 | 제공 경로(참고) | 필요한 항목 |
|---|---|---|---|
| 1 | Google Play 리뷰 | Play Console → 사용자 리뷰 내보내기(월별 CSV, "Download reports → Reviews") | 리뷰 작성 일시, 별점, 리뷰 내용, 앱 버전(Version Name/Code), 언어, 리뷰 링크 |
| 1 | 버전별 출시 이력 (플랫폼별) | Play Console 출시 기록, App Store Connect 버전 기록, 원스토어 개발자센터 | 플랫폼, 버전, 실제 배포일(단계적 출시 시작일과 100% 완료일 구분 가능하면 함께), 주요/핫픽스 구분 |
| 1 | 패치노트 | 공식 카페·라운지 공지 원문 또는 내부 정리본 | 버전 또는 공지일, 주요 변경 사항 |
| 2 | App Store 리뷰 | App Store Connect 평가 및 리뷰(또는 Customer Reviews API) | 작성일, 별점, 제목, 내용, (가능하면) 앱 버전 |
| 3 | 원스토어 리뷰 | 원스토어 개발자센터 | 작성일, 별점, 내용, 앱 버전 |

- **기간:** 서비스 시작(2021-06)부터 현재까지. 어렵다면 최근 12개월만 주셔도 됩니다.
- **형식:** 스토어에서 내려받은 원본 파일 그대로 주시면 됩니다(CSV/엑셀/JSON). 별도 가공은 필요 없습니다.

## 데이터 처리 약속

- 해커톤 과제 분석과 발표 목적으로만 사용합니다.
- 작성자 이름·닉네임·기기 식별 정보는 저장하지 않거나 마스킹합니다.
- 리뷰 원문은 공개 저장소(GitHub)에 올리지 않습니다. 발표 자료에는 집계 결과와 짧은 인용만 사용합니다.
- 대회 종료 후 요청하시면 원본 데이터를 삭제하겠습니다.
- 제공 범위나 사용 조건에 제한이 있으면 알려 주세요. 그 범위 안에서만 사용하겠습니다.
