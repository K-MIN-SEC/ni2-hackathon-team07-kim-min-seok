01 핵심 동작
| 점검 | 예상 결과 | 결과 |
|---|---|---|
| 시연용 CSV 4개(연도별)를 한 번에 넣기 | 원본 전체 집계와 같음: 6,349건, 긍정 4,384·부정 943·혼합 423·중립 599 | PASS (일치) |
| 파일 1개 → 두 번째 파일 누적 | 1,516건 → 4,610건, 증가 건수와 비율 변화(%p) 표시 | PASS |
| 같은 파일을 다시 누적 | "새로 더해진 리뷰가 없습니다", 화면 그대로 | PASS |
| 교체 / 취소·Esc | 교체는 새 파일만으로 계산, 취소는 화면 유지 | PASS |
| 요약 칸·주제 표 숫자 클릭 | 근거 리뷰 목록 건수 = 표 숫자 (예: 버그·부정 636건) | PASS |
| 키워드 주제·감성 선택, 차트 '표로 보기' | 차트·표 제목이 선택에 맞게 바뀜, 표 열기·닫기 | PASS |
| 로컬 분류 서버 정상 리뷰 3건 (Pages에는 없음) | 미세조정 모델로 판정, 약 0.5초 | PASS |

02 잘못된 입력
| 입력 | 예상 결과 | 결과 |
|---|---|---|
| 빈 CSV | "파일이 비어 있습니다", 기존 화면 유지 | 처음 FAIL(영문 오류 그대로 노출) → 수정 후 PASS |
| 필수 열 없는 CSV, CSV가 아닌 파일(이미지) | 빠진 열 이름 안내, 기존 6,349건 유지 | PASS |
| 없는 날짜(2026-02-30, 13월, 25시)가 섞인 CSV | 그 행만 빼고 계산, "읽을 수 없는 1행 제외 (4행)" 안내 | 처음 FAIL(파일 전체가 실패) → 수정 후 PASS |
| 정상 파일 + 빈 파일을 함께 넣기 | 정상 파일만 반영, 실패한 파일 이름과 이유 표시 | PASS |
| 파일 이름·내용에 <script>, <img onerror> | 글자로만 보이고 실행 안 됨 | PASS (실행 0회) |
| 리뷰 검색에 ( [렉 .* <b>x</b> 공백, 500자 | 오류 없이 글자 그대로 검색 | PASS (78 / 0 / 1 / 0건, 공백은 전체) |
| 분류 서버에 잘못된 요청 14종 (빈 목록, 51건, 별점 0·6·"a", 깨진 JSON 등) | 400·404·415와 안내 문구 | PASS |

## 칸 3. 완성 폴더 위치 · 남은 한계

---
[완성 폴더] 팀 저장소 최상위 (GitHub Pages가 이 폴더를 배포)
- index.html — 첫 화면. 저장소 최상위에 있음
- review-analysis/dashboard/dashboard.html — 대시보드. CSS·JS·차트·예시 데이터가 이 파일 하나에 들어 있음(별도 style.css·script.js·assets 폴더 없음)
- review-analysis/data/demo/ — 시연용 CSV 4개 (작성 연도별, 모두 누적하면 전체 6,349건과 같음)
- TEST_REPORT.md — 기능 테스트 전체 기록

[저장값] localStorage에는 화면 모드(라이트·다크) 하나만 저장합니다. 지금 쓰는 브라우저에만 남고 다른 기기·브라우저에는 옮겨지지 않습니다. 불러온 CSV는 저장하지도, 외부로 보내지도 않습니다.

[남은 한계]
- 웹 대시보드는 라벨이 붙은 CSV를 집계합니다. 새 리뷰에 감성·주제를 붙이는 분류기는 로컬 Python(분류 서버)에서 돌려야 하고, Pages에는 없습니다.
- 정답 라벨의 1/3(2,030건)은 AI가 판정했습니다. 어려운 리뷰 정확도 89.7%는 "AI가 만든 정답과의 일치도"입니다.
- App Store 리뷰가 150건뿐이라 결과는 사실상 Google Play 기준이고, 최근 6개월 리뷰가 57건이라 추세 수치는 불안정합니다.
- 중립 판정이 가장 약하고(F1 0.60), 반어·"(수정)" 리뷰·걱정·응원 말투는 아직 틀립니다.
- 모바일에서 차트 막대와 섹션 제목 옆 '#' 링크는 누르는 영역이 24px보다 작습니다.
- 실제 휴대폰, Safari·Firefox, 스크린리더로는 확인하지 못했습니다.
