# 다른 게임 적용 테스트: 메이플 키우기 (2026-11-27)

달토끼 키우기 리뷰로만 학습한 분류기(규칙 + ML + 미세조정 임베딩, 분류 서버와 같은 경로)를 **다시 학습하지 않고** 다른 게임 리뷰에 그대로 돌렸을 때 얼마나 맞는지 확인했다. 결과가 좋으면 시연에 반영할 예정이다.

## 1. 방법

| 항목 | 내용 |
|---|---|
| 대상 | 메이플 키우기 (넥슨·에이블게임즈). Google Play `com.nexon.ma`, App Store `6739616715` |
| 수집 | 8,054건 (Google Play 7,554건 전량, App Store는 공개 피드 한도인 최근 500건) → `data/maple/reviews.csv` |
| 표본 | 무작위 300건 (seed 2026, Google Play 277 + App Store 23) → `work/maple/sample.jsonl` |
| 정답 | Claude가 300건을 직접 판정. 달토끼 때와 같은 기준(`work/manual/RUBRIC.md`)을 썼고, 별점은 보지 않고 **내용만으로** 판정함. **모델을 돌리기 전에** 판정을 끝냄 → `work/maple/gold.jsonl` |
| 비교 | `python scripts/cross_game_eval.py compare` → `work/maple/compare.json`(지표), `work/maple/compare_rows.csv`(리뷰별 결과) |

쉬움/어려움 구분은 달토끼와 같다(규칙이 확신하면 쉬움, 아니면 어려움이라 ML에 넘김). 달토끼에서는 쉬운 리뷰의 정답이 곧 규칙 판정이라 쉬운 쪽 정확도를 잴 수 없었는데, **이번에는 300건을 모두 따로 판정했으므로 쉬운 리뷰의 정확도도 실제 값이다.**

## 2. 결과

### 감성 (긍정·부정·중립·혼합)
| 방법 | 전체 300 | 쉬움 162 | 어려움 138 |
|---|---|---|---|
| **모델 (서버와 같은 경로, 적용 전)** | **88.0%** | 85.8% | **90.6%** |
| 모델 (6장 개선 적용 후) | 91.0% | 91.4% | 90.6% |
| 규칙만 | 75.0% | 85.8% | 62.3% |
| 별점만 (4~5 긍정, 3 혼합, 1~2 부정) | 78.3% | | |
| *참고: 달토끼 어려운 리뷰 (교차검증)* | | | *89.7%* |

- 어려운 리뷰에서는 **달토끼와 비슷한 수준(90.6% 대 89.7%)**이 나왔다. 다른 게임으로 바꿔도 감성 판정은 유지된다.
- 긍정 / 부정·혼합 / 중립의 3분류(대시보드에서 묶어 보여주는 방식)로 보면 89.0%다.
- 틀린 36건 중 **23건이 '쉬운' 리뷰**에서 나왔다. 원인은 3장 1번에 있다.

### 주제 (과금·버그·콘텐츠·운영 등 8개)
| 지표 | 메이플 전체 | 메이플 어려움 | *달토끼 어려움* |
|---|---|---|---|
| 주제 묶음 완전 일치 | 70.7% | 47.1% | *63.7%* |
| 주제 + 주제별 감성 완전 일치 | 62.7% | 42.8% | *56.9%* |
| 주제가 맞았을 때 그 주제의 감성 일치 | 88.9% | 90.2% | |

| 주제 | F1 | 정답 / 모델 건수 |
|---|---|---|
| 광고 | 0.90 | 14 / 15 |
| 버그 | 0.80 | 55 / 60 |
| 밸런스/성장 | 0.75 | 29 / 27 |
| 과금 | 0.69 | 54 / 54 |
| 캐릭터/아트 | 0.62 | 4 / 9 |
| UI/편의성 | 0.53 | 7 / 12 |

- 주제는 달토끼보다 **분명히 떨어진다**(어려운 리뷰 완전 일치 63.7% → 47.1%).
- 광고·버그·밸런스/성장은 잘 맞는다. **운영과 콘텐츠는 절반 가까이 놓친다.**

## 3. 틀린 원인

### ① 짧은 리뷰를 규칙이 '중립'으로 확신함 (감성 오류 36건 중 20건)
규칙 사전에 없는 단어로 쓴 짧은 리뷰를 규칙이 '중립'으로 판정하고, 이것을 확신 건으로 처리해 ML에 넘기지 않았다.
예: "과금 미쳣음", "광고 겁나 많이 나옴", "확률 조작의 대명사", "조작겜", "유저기만??", "역시 넥슨이넥슨했다", "젬없다", "추억 돋는당", "시간잘가네"

**개선 후보 실험** (`work/maple/variant_rule_neutral_to_ml.json`): 규칙이 '중립'이라고 한 쉬운 리뷰(26건)도 ML에 넘기면
| | 감성 정확도 |
|---|---|
| 지금 (서버와 같은 경로) | 88.0% |
| 규칙 '중립'만 ML로 넘김 | **91.0%** (+3.0%p, 쉬운 리뷰 85.8% → 91.4%) |
| 모든 리뷰를 ML로 판정 | 90.7% |

단, **달토끼에서는 이 변경의 효과를 정확도로 잴 수 없다.** 달토끼에서 쉬운 리뷰의 정답은 규칙 판정 그 자체였기 때문이다. → 적용 결과는 6장에 있다.

### ② 메이플에만 있는 운영 이슈와 용어 (주제 오류)
- 운영을 놓친 예: 해외 **권역 접속 제한**, **서버 통합·이동** 요청, 문의해도 답이 없음, 계정 초기화, "기만", 환불 공지. 달토끼 리뷰에는 거의 없던 유형이다.
- 콘텐츠를 놓친 예: 점프맵, 길드 가입 쿨타임, 파티퀘스트·마을퀘스트, "컨텐츠 좀 많이".
- 과금을 놓친 예: "블랙패턴", "돈 개많이듬", "넥슨은 유저를 돈으로 본다", 코스튬 능력치 캐시. 메이플 고유 과금 용어(스타포스·큐브·주문서)는 대부분 '확률' 같은 일반 단어와 함께 나와서 잡혔다.
- 달토끼 주제 사전에 게임 고유 단어("니아" 등)가 있어서, 다른 게임에서는 그 부분이 쓸모없다.

### ③ 정답 쪽 한계
- 정답은 **판정자 한 명(Claude)**이 만든 것이고 표본은 300건이다. 정확도에 대략 ±3~4%p 오차가 있다고 보는 게 맞다.
- 반어를 놓쳤을 수 있는 건이 2건 있다. "원작을 그대로 고증하는 갓겜입니다"와 "역시 메이플!!"은 둘 다 별점 1점인데, 내용만 본 정답은 긍정이었다. 모델은 별점을 함께 보므로 앞의 것을 부정으로 판정했고, 뒤의 것은 규칙이 중립으로 판정했다. 정답은 고치지 않고 그대로 두었다. 둘 다 부정으로 고치면 모델 정확도는 88.3%가 된다.
- 결제 후 미지급("광고제거 샀는데 적용 안 됨")은 달토끼 정답 관례대로 버그로만 판정했다. 모델은 과금도 함께 붙이는 경우가 있어서, 이 차이 일부는 오류라기보다 관례 차이다.

## 4. 시연 반영 판단

| 항목 | 판단 |
|---|---|
| 감성 | **시연에 써도 됨.** 다시 학습하지 않은 다른 게임에서도 88%(어려운 리뷰 90.6%)로 달토끼와 같은 수준 |
| 주제 | **수치를 앞세우지 말 것.** 운영·콘텐츠는 절반 가까이 놓침. 보여주더라도 "광고·버그·밸런스는 잘 잡고, 운영·콘텐츠는 게임별 단어 보강이 필요하다"고 같이 말하는 편이 안전 |
| 빠른 개선 | ① 규칙 '중립' 짧은 리뷰를 ML로 넘기기 (+3%p) → **적용함 (6장)** ② 운영·콘텐츠 사전에 일반 단어 추가 (권역, 서버 이동/통합, 기만, 점프맵, 파티퀘 등) → 아직 안 함 |

## 6. 적용: 규칙 '중립'을 ML로 넘기기

`scripts/ml_classify.py`의 `NEUTRAL_TO_ML = True`. 규칙이 확신하더라도 '중립'이라고 판정한 리뷰는 ML이 다시 판정한다. 분류 서버(`/api/classify`)와 `ml_classify.py predict`에 적용된다. 모델은 다시 학습하지 않았다. 달토끼 교차검증(`ml_classify.py eval`)만 기록된 수치를 재현하도록 예전 경로를 쓴다.

### 메이플 300건 (적용 전 → 후)
| 지표 | 전 | 후 |
|---|---|---|
| 감성 정확도 | 88.0% | **91.0%** |
| 감성 macro F1 | 0.745 | 0.783 |
| 3분류(긍정 / 부정·혼합 / 중립) | 89.0% | 92.0% |
| 쉬운 리뷰 감성 | 85.8% | 91.4% |
| 주제 + 주제별 감성 완전 일치 | 62.7% | 65.7% |
| 주제 묶음 완전 일치 | 70.7% | 71.0% |

- 어려운 리뷰는 원래 ML이 판정하던 것이라 변화가 없다(90.6%).
- 정답이 '부정'인데 '중립'으로 판정한 건이 11건에서 4건으로 줄었다.
- 적용 전 결과는 `work/maple/compare_before.json`과 `compare_rows_before.csv`에 남겨 두었다.

### 달토끼 6,349건에 주는 영향
- 규칙이 확신한 4,351건 중 '중립' **498건**이 ML로 넘어간다. 그중 **42건**의 판정이 바뀌고(긍정 29, 부정 13), 456건은 그대로 중립이다.
- 바뀐 42건을 읽어 보면 거의 다 바로잡힌 것이다. 예: "캐릭터가 예뻐여" → 긍정, "로딩너무김" → 부정, "거짓 뽑기 속지마셈" → 부정, "패스종류만 10개쯤" → 부정, "무자본도쉽게할수있어요" → 긍정.
- 애매한 것은 2건이다: "👂 🦻"(별점 5점이라 긍정으로 판정), "Kill"(별점 1점이라 부정으로 판정).
- 목록은 `work/maple/dalto_neutral_to_ml.csv`에 있다.
- **대시보드 수치는 바뀌지 않았다.** 대시보드는 학습 정답 파일(`data/reviews_labeled.csv`)로 만들기 때문이다. 이 정답 파일에는 위 42건이 아직 '중립'으로 남아 있다.

### 서버 동작 확인 (로컬, 포트 8766)
| 입력 | 별점 | 결과 | 판정 출처 |
|---|---|---|---|
| 과금 미쳣음 | 1 | 부정 (과금: 부정) | ml (전에는 rule, 중립) |
| 광고 겁나 많이 나옴 | 1 | 부정 (광고: 부정) | ml |
| 확률 조작의 대명사 | 1 | 부정 (과금: 부정) | ml |
| 추억 돋는당 | 5 | 긍정 | ml |
| 그냥 그래요 | 3 | 중립 | ml |
| 재밌는데 렉이 심해요 | 4 | 혼합 (버그: 부정) | ml |
| 굿 | 5 | 긍정 | rule (규칙 '긍정'은 그대로) |

모델 로딩은 17.6초, 리뷰 7건 판정은 약 0.2~0.3초 걸렸다.
