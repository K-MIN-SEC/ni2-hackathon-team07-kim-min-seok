# 오토 밸런싱 (Auto Balancing)

방치형 RPG의 **성장·재화 시뮬레이션**과 **이벤트 전후 비교**를 브라우저에서 바로 해 보는 도구입니다.
2026 NI2.0 AID 해커톤 7팀 카페인 중독 (서일대학교 AI게임융합학과) · 연계 기업 ㈜에이블게임즈

> ⚠ 앱의 모든 수치는 **가상 샘플 데이터**입니다. ㈜에이블게임즈의 실제 데이터나 공식이 아닙니다.

## 파일 구성

| 파일 | 내용 |

| `index.html` | 웹앱 전체 (HTML·CSS·JavaScript 한 파일, 외부 라이브러리·서버·로그인 없음) |
| `tests/engine.test.js` | 계산 엔진 검증 테스트 20개 (`index.html` 안의 엔진 코드를 그대로 꺼내 검사) |
| `project-plan.md` | 기업 조사·문제 정의·데이터 검수 기획서 |

## 확인 방법

1. **바로 열기**: `index.html`을 더블클릭하면 브라우저에서 열립니다. 빌드나 설치가 필요 없습니다.
2. **휴대폰 화면**: 브라우저 개발자 도구(F12) → 기기 모드(Ctrl+Shift+M)로 확인하거나, GitHub Pages에 올린 뒤 휴대폰으로 접속합니다.
3. **테스트**: Node.js가 있으면 아래 명령으로 엔진 테스트를 실행합니다.
   ```
   node --test tests/engine.test.js
   ```

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다 (`index.html`이 저장소 맨 위에 있어야 합니다).
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다. 빌드 단계는 없습니다.

## 시연 순서 (약 2분)

1. 처음 열면 샘플 프로젝트와 이벤트 1개(3일 차부터 3일간 경험치 2배)가 들어 있습니다.
2. **결과**에서 성장 곡선·재화 흐름·수급처 비중·자동 분석을 확인합니다.
3. **② 유저 모델**에서 캐주얼 / 일반 / 헤비를 바꿔 결과가 어떻게 달라지는지 봅니다.
4. **③ 이벤트**에서 "골드 100만 지급" 등을 추가하고, 기준 대비 해금 시점·레벨 차이를 비교합니다.
5. **결과 CSV 내려받기**로 시간별 기록을 엑셀에서 엽니다.

## 첫 버전 범위

- 포함: 기능 ① 성장·재화 시뮬레이션, 기능 ② 이벤트 전후 비교, 입력 검증, 자동 저장(브라우저 localStorage), 결과 CSV 내보내기
- 다음 단계: 기능 ③ 목표 기반 자동 밸런싱(콘텐츠 진입 목표 → 재화량 자동 조정 → 수정 CSV 내려받기), CSV 가져오기, 복수 유저 모델 비교
- 제외: 로그인, 결제, 서버, 생성형 AI 기능

## 계산 규칙 요약 (가정)

앱 화면의 "계산 규칙 보기"에 전체 내용이 있습니다.

- 1분 단위 이산 시간 시뮬레이션. 확률 요소가 없어서 같은 입력이면 항상 같은 결과가 나옵니다.
- 하루는 00:00에 접속해서 `하루 접속 시간`만큼 플레이하고, 나머지는 오프라인입니다.
- 접속 처리 순서: 방치 보상 수령 → 입장권 충전 → 일일 보상 → 이벤트 지급 → 레벨업·강화·스테이지 갱신.
- 접속 중: 던전(입장권·해금·남은 시간 조건 충족 시) 우선, 아니면 자동사냥. 던전 시간에는 사냥 보상 없음.
- 공격력 = (기본 + 레벨당 × (레벨−1)) × (1 + 강화당 %)^강화 단계 → 공격력으로 스테이지 진행 → 스테이지로 사냥·던전 보상 증가.
- 강화는 접속 중에만 실행. 오프라인 보상은 최대 누적 시간까지만 쌓이고 다음 접속 때 받습니다.
- 이벤트 배율은 겹치면 곱하고, 할인은 (1−a)(1−b)로 합칩니다. 이벤트가 끝나도 얻은 성장은 유지됩니다.
