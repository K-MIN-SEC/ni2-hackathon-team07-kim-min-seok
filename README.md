## 지금 하고 있는 것: 유저 리뷰 감성 분석 대시보드

**과제:** 스토어 리뷰를 긍정·부정과 주제(과금, 버그, 콘텐츠 등)로 나눠 보여 준다. 공개 리뷰 일부를 샘플로 쓰고 출처를 표시한다.

**대상 사용자:** 게임 개발사·배급사의 운영 담당자와 기획자

**대상 게임:** 에이블게임즈의 **달토끼 키우기**, **메이플 키우기**(넥슨코리아 공동 개발·서비스)

**해결하려는 문제 (가설):** 리뷰가 계속 쌓이는데, 한 리뷰 안에도 여러 주제와 긍정·부정 의견이 섞여 있어서 무엇을 칭찬하고 무엇에 불만인지, 어떤 불만이 반복되는지 하나하나 읽어야 파악할 수 있다. 기업 인터뷰는 하지 않았으므로 문제는 가설로 둔다.

**만들려는 것**

1. 리뷰 전체의 감성(긍정·부정·혼합·중립)과 주제별 긍정·부정 분류
2. 호평 주제와 불만 주제를 나란히 보여 주고, 불만을 언급한 리뷰 수 순으로 개선 검토 순위 제시
3. 모든 숫자에서 근거가 된 원래 리뷰(작성일·출처)로 이동
4. 업데이트(앱 버전) 전후로 반응이 어떻게 달라졌는지 비교 (검토 중)

**원칙**

- 새 리뷰 분류에는 **LLM을 쓰지 않는다.** 규칙과 머신러닝(예: TF-IDF + 로지스틱 회귀)으로 분류한다.
- 별점과 본문 감성은 따로 다룬다.
- 공개 리뷰 일부를 쓴 결과임을 화면에 밝히고, 실제 리뷰와 샘플 데이터를 섞지 않는다.

## 아직 정하지 않은 것
