## 4. 미실행·한계

- 이 보고서의 PASS는 집계·필터·표시 기능에 대한 것이다. **의견 분류 자체의 정확성(팀의 원문 대조 검수)은 NOT RUN**이다. 의견 111건 중 108건이 미검수, 3건이 판단 보류 상태다.
- 브라우저 점검은 내장 브라우저(Chromium) 한 종류에서만 했다. Safari·Firefox는 NOT RUN이다.
- `file://`로 직접 열면 브라우저 보안 정책 때문에 데이터를 불러오지 못한다. 이 경우 실행 안내 메시지가 뜨도록 코드를 넣었지만 실제로 확인하지는 않았다(NOT RUN). 실행은 `node tools/serve.js`를 사용한다.
- 키보드 조작(Enter로 차트 항목 선택) 코드는 넣었지만 수동 점검은 하지 않았다(NOT RUN).
